# パタプラ v1.3｜学習画面の簡素化と会議・ファシリの配分
更新日：2026-11-24

## 変更点
- 学習周回の手動選択欄を廃止。今日の学習プランまたは教材の進捗から自動判定し、記録一覧の1〜3周目の編集機能は維持する。
- 本文・和訳・解説を常時展開し、折りたたみ操作と見出しバーを廃止。
- レッスン本文末尾に「↑ トップに戻る」ボタンを配置。ページ最上部へスクロールする。
- 口語表現のType B/C選択を設定画面へ移動。端末内に保存し全レッスンに共通適用。学習画面の音声選択欄は非表示。音声未登録やエラーは従来どおり表示する。
- 会議1〜3→ファシリ1、会議4〜6→ファシリ2、以後同様。会議54の後にファシリ18、会議55〜56の後にファシリ19。計75件すべて維持。既存完了IDと日付は保持し、当日確定済みの学習プランは維持、翌日以降は新順序の未完了レッスンから進む。
- v1.2の文字サイズ、テーマ、完了・取消、手動更新ボタン、オフライン保存は維持。
