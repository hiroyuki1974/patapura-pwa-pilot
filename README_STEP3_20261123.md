# パタプラ Step 3 試験版 v0.6（2026-11-23）

試験URL: https://hiroyuki1974.github.io/patapura-pwa-pilot/preview-step3-20261123/

既存v0.5を基礎に、全217レッスンの統合JSONと、教材区分ごとのMP3複数取り込みを追加。購入教材の本文・JSON・MP3はこのリポジトリに含めない。ユーザーが選択したファイルはブラウザ内のIndexedDBに保存し、サーバーへ送信しない。

## 変更点

- Step 2の `patapura-display-library-v1` を1ファイルで検証・保存。62/56/19/80件の4区分を表示。
- v0.5の本文描画を再利用。復習専用区分とType A/B/C共通本文を保持。
- `教材区分:2桁番号:音声種別` のIDで514候補を区別。区分は取り込み前に選択する。同名ファイルの内容だけから教材を判定することはできない。
- 音声を1件ずつ保存。同一バイナリはSHA-256で省略し、内容変更は同じIDに原子的に置換。不明な名前、範囲外番号、区分に合わない種類、MP3ヘッダー不正はエラー表示。
- 取り込み件数・成功・置換・省略・エラーを表示。中断は現在の1件の終了後に停止し、保存済み分を維持。容量不足時も既存データを維持して停止。
- 音声切替、未登録表示、レッスン別完了記録と選択状態の復元。v0.5のIndexedDB・native audio・Blob/SW Range比較・進捗バックアップを維持。
- 試験版専用DB `patapura-pwa-step3-trial-v1`、キャッシュ接頭辞 `patapura-step3-trial-shell-`、子ディレクトリ限定SW。正式版のデータは自動移行しない。
- rootの `sw.js` は試験版パスを除外する2行のみ追加。既存v0.5のページ・音声・進捗の処理は維持。元のv0.5全体は `preserve-v0.5-20261123` ブランチに保全。

## iPhone 17での確認手順

1. ZIPを「ファイル」アプリで展開し、`PATAPURA_DISPLAY_ALL217_v1.0_20261123.json` と各区分Lesson 1〜3のMP3をiPhoneから選べる場所へ置く。大容量ZIPをアプリ内では展開しない。
2. Safariで試験URLを開き、画面に **v0.6・2026.11.23** があることを確認する。既存v0.5画面になる場合は既存版URLを一度開き直して更新を待ち、その後試験URLを再度開く。初回はオンラインで起動する。
3. 「統合JSON（全217件）を取り込む」を押し、上記JSONを1回選択する。62/56/19/80件、合計217件を確認する。
4. 「取り込み先の教材区分」を選び、その区分のMP3だけを複数選択する。通常版6本、会議版6本、ファシリテーション6本、口語表現9本の順で計27本を取り込む。各処理が終わるまで画面を開いておく。
5. 各区分のLesson 1〜3を選び、通常／復習、Type A/B/Cを切り替える。本文、登録済み表示、再生内容、シークを確認する。Lesson 4以降では「未登録」を確認する。
6. 同じ6本を再取り込みし、「同一のため省略6件」、登録本数が増えないことを確認する。
7. レッスンを1つ完了にし、別の区分・レッスンへ移動する。Safariを閉じて開き直し、選択と完了記録が戻ることを確認する。
8. ホーム画面へ追加し、そこからオンラインで一度起動する。Safariとホーム画面では保存領域が異なる場合があるため、本文・音声がなければその起動方法側で取り込む。
9. 機内モード＋Wi-Fiオフで起動し、本文閲覧、登録済み音声の再生・シーク、完了記録の保存を確認する。
10. 単一MP3を再生して画面をロックし、3分間の再生継続、ロック画面からの一時停止・再開を確認する。これはiPhone実機で最終判定する。
11. オンラインへ戻し、ページの再読み込み後も本文・音声・記録が残ることを確認する。既存版v0.5でも従来データが残ることを確認する。

一括取り込みはファイル名と選択区分で対応付けるため、区分を誤って選ぶと、同名MP3の内容の違いまでは判別できない。ブラウザのサイトデータ消去・OSによる削除に備え原ファイルは保管する。全514本の実在確認とロック中の複数MP3自動連続再生は今回の完了条件外。
