# パタプラ v1.1｜3周回・日付修正・完了操作の改善
更新日：2026-11-24

## v1.0の実機
ユーザーがv1.0がきちんと動作していると報告。v1.0は preserve-v1.0-20261124 に保全。

## v1.1
- 1〜3周目を独立管理。既存の progress.lessons を1周目として維持し、2・3周目は progress.rounds[2] / [3] に追加する。音声・本文は周回共通。
- 教材ごとに1周目を全件終了すると翌学習日に2周目のLesson 1へ進む。3周目も同様。3周目終了後は当該教材の全課程完了。日々のプランは同日内で固定する。
- 学習記録一覧に1〜3周目の日付を表示。日付または空欄を押し、任意の学習日に変更・追加できる。記録削除は確認を経て選択したセルだけを削除する。
- 学習日自動記録は従来どおり日本時間。海外・深夜等は記録一覧で修正可能。日付だけを修正しても完了状態は保持する。
- 既存の「完了して次の教材へ」を廃止。「学習完了」と「今日の学習へ戻る」をプレーヤー直下に独立配置。前者は選択中のレッスンと周回の記録のみ、後者は記録変更なしで日次画面へ戻る。3教材終了時は日次画面に3/3完了。
- 通常の復習音声が登録済みの場合は「復習・登録済み」表示を省略。口語表現はType B/C選択を残す。未登録・エラーは表示する。
- 旧形式の進捗バックアップにも対応。新形式のバックアップには2・3周目を含める。

## 保存と更新
IndexedDB、本文キー、audio/progressストア、manifest id/start_url/scope、公開URLは変更なし。
同じホーム画面アイコンからオンライン起動・終了・再起動で更新。本文217件・音声297本の再登録不要。

## 実機確認
v1.1への更新後、既存の日付が1周目に表示されるか、2・3周目が空欄から記録できるか、日付の変更・削除、復習表示の省略、Type B/C、完了と戻るの動作を確認する。実際に学習していない周回を試すためだけに記録する必要はない。コード検査・模擬試験は完了、iPhone実機は未確認。
