## 重要
- **v0.7と同じURL・同じホーム画面アイコンを使用。アプリの削除・再インストールは不要。**
- 既存IndexedDB `patapura-pwa-step3-trial-v1` の `audio` / `progress`、本文キー `display-library:all217`、manifestの `id` / `scope` / `start_url` は変更しない。

- 変更前のv0.7はGitHubブランチ `preserve-v0.7-20261123` に保全済み。

## iPhoneでの操作（第一候補）
1. すでに使っている**ホーム画面のパタプラアイコン**から開く。インターネット接続中に再読み込み・再起動し、**v0.8**と表示されることを確認する。新しいアイコンを作らない。
2. 「今日の学習」から「MP3登録へ」を押す。登録パネルは自動的に開く。
3. 「**『パタプラ資料』フォルダを選ぶ**」を押し、「ファイル」内の `パタプラ資料` フォルダを選ぶ。iOSのフォルダピッカーでは、そのフォルダへ移動して「開く」を押す場合がある。
4. 事前検査で次の表示を確認する。
   - ビジネス 62/62
   - 会議編 56/56
   - ファシリテーション編 19/19
   - 口語表現 Type B・C 160/160
   - 合計297本。以前の試験用フォルダは自動的に無視する。
5. **「検査済みの復習MP3を登録開始」**を押し、処理が完了するまで**iPhoneをロックせずアプリを前面に表示**する。途中中断・アプリ終了で既存登録分は消えない。
6. 完了後、ホームのビジネス・会議/ファシリ・口語表現を開き、再生テストする。日次学習の初期音声はビジネス・会議/ファシリが「復習」、口語表現が「Type B」。Type Cへは音声種類から切替可能。

## フォルダの前提
選択する `パタプラ資料` の直下またはその下層に、次の名前の**4つのフォルダ**が存在すること。
- `パタプラビジネス`（`Review-Lesson01.mp3` 〜 `Review-Lesson62.mp3`）
- `パタプラ会議`（同01〜56）
- `パタプラファシリテーション`（同01〜19）
- `パタプラ口語表現`（`Lesson01-TypeB.mp3` 〜 `Lesson80-TypeC.mp3`）

フォルダ選択ができない場合は**4教材フォルダを1つずつ**選ぶことも可能。各フォルダの必要数が全件揃っていれば登録できる。さらに従来の「この区分のMP3を複数選択」も残してある。

## 安全性・制限
- 誤った教材区分・レッスン番号・重複・不完全なフォルダの登録は事前検査で停止。対象外フォルダや初回用音声は無視する。
- 同名の `Review-Lesson01.mp3` はフォルダ名から教材を識別し、別のデータIDで保存する。
- 取り込みは1本ずつ行い、同じハッシュ・サイズの保存済み音声はスキップ。中断した場合、同じフォルダを再選択して再開できる。
- 大容量のためiPhoneのアプリ専用保存容量に制限がある場合は停止する。**本体空き容量が十分でもSafari側の保存可否は実機で確認が必要。**
- 本版のコードの構文・振り分け事前検査は実施済み。**v0.8でのiPhoneフォルダ選択・全297本保存は未実機検証**。
