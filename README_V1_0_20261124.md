## v1.0の変更
- 学習・記録一覧・設定の3画面へ分離。
- 日次3教材のカテゴリ、レッスン番号、完了状態、操作を横並びにした。ヘッダーや説明、パネルの余白を縮小。
- レッスン選択は教材とレッスンを横に配置。本文左右余白、行間、段落間隔を縮小。音声プレーヤーは既存機能維持。
- 会議・ファシリテーションを75件の連続リストとして扱う。会議1、ファシリ1、会議2、ファシリ2…ファシリ19、その後会議20〜56。内部の教材IDは従来のまま、同名MP3を区別する。
- 記録一覧はビジネス62、会議・ファシリ75、口語表現80の3タブ。完了日、未完了、完了数を表示。レッスンを押すと学習画面へ移動。
- 現行の記録形式（1レッスンにつき完了日1件）を参照する。過去の公式サイトの記録を取り込んだり、存在しない復習履歴を生成したりしない。複数回の復習履歴管理は別機能。
- 自動（端末設定）→ライト→ダークの手動切替を追加。選択は端末内に保存。
- 取り込み、保存状況、バックアップ、診断、消去操作は設定画面に分離。
