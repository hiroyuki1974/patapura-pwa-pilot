## 状況

## v0.9で変更したこと
1. 選択中のレッスンに「**完了して次の教材へ**」を追加。未完了であれば完了記録を保存し、当日の残りの教材（ビジネス → 会議・ファシリテーション → 口語表現）へ移動する。すでに完了済みの場合は再度記録を消さず次へ進む。3教材とも完了時は今日の学習画面に戻る。
2. 従来の「学習完了にする」は残す（手動で記録を修正する場合）。
3. 本文JSONの再取り込み、学習記録バックアップ、実機チェックを折りたたむ。
4. 危険な「試験データだけを消去」を技術診断の内側に移動。初期表示では見せない。

## 継続利用・データ保全
- 既存ホーム画面アイコンをそのまま使う。再インストール不要。
- IndexedDBは **patapura-pwa-step3-trial-v1**（audio、progress）、本文キー **display-library:all217** のまま。
- manifestのid/scope/start_urlは「./」のまま。
- 音声を二重にアップロード・再登録する必要はない。MP3と本文はGitHubに含めない。
- SWキャッシュのみ **patapura-step3-trial-shell-v09-20261124** に更新。
- 更新前のv0.8は **preserve-v0.8-20261124** ブランチに保全済み。
